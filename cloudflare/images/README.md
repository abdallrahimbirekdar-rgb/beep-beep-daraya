# صور سوق داريا على R2

الكود جاهز، لكنه لا ينقل الصور أو يفعّل R2 تلقائيًا. يظل رفع الصور إلى Supabase ما لم يضف المسؤول r2UploadUrl إلى BEEP_CONFIG.

## التفعيل من Codespaces

من مجلد المشروع، بعد تسجيل الدخول لحساب Cloudflare:

```bash
npx wrangler login
npx wrangler r2 bucket create daraya-images
cd cloudflare/images
npx wrangler deploy
```

قد يطلب Cloudflare تفعيل R2 وإضافة وسيلة دفع حتى مع استخدام الحدود المجانية. لا تشترِ Workers Paid لمجرد التجربة.

أرسل رابط Worker الناتج (رابط عام، وليس مفتاحًا). نضيف `r2UploadUrl: 'https://daraya-images.ACCOUNT.workers.dev/upload'` إلى إعدادات الموقع بعد الاختبار. لا توضع مفاتيح سرية في الموقع. يستخدم Worker مفتاح Supabase العام ورمز جلسة المستخدم للتحقق من صلاحية manages_store قبل الرفع.

## النقل

قبل تحويل الصور القديمة: نحصر روابط Supabase الموجودة في stores.image وproducts.image وproducts.gallery وstore_page_photos؛ نحفظ نسخة من الروابط والبيانات، ننقل الصور والمصغرات إلى R2، نتحقق من الملفات، ثم نحدّث الروابط مع حماية revision. لا تحذف ملفات Supabase قبل تأكيد النقل وإمكانية الرجوع. لا تغيّر الصور الخارجية أو صور الأمثلة في المستودع. هذه المرحلة لم تنفذ بعد، وتحتاج الاتصال بالحساب.

## المصروفات

راقب Usage في Supabase وR2 وWorkers دوريًا، وفعّل إشعارات الفوترة المتاحة من لوحة Cloudflare. لا يمثل التنبيه حدًا يوقف الإنفاق. تُقدّم الصور هنا عبر Worker، لذلك تدخل قراءة الصور ضمن عدد طلباته إلى جانب عمليات R2. يمكن لاحقًا ربط نطاق R2 عام لتقديم الصور مع التخزين المؤقت وتقليل طلبات Worker.

## الصور الجديدة

يقلل الموقع أبعاد الصور إلى 1600 بكسل كحد أقصى ويجرّب ضغط WebP، ويحتفظ بالملف الأصغر، مع مصغّرة منفصلة 400 بكسل. تبقى حدود 1.5 ميغابايت و50 صورة كما هي. لا تخفض جودة الصور القديمة تلقائيًا. التحميل الكسول والمصغرات موجودان بالفعل.
